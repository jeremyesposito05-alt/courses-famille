Comptes et tâches

Essai de synchronisation avec deux comptes personnels. Cette page n'utilise pas la base familiale actuelle.

Aucun déploiement en production. Utilise uniquement un nouveau projet Firebase de test et des données fictives. La configuration réelle de la famille est refusée par ce prototype.

1. Configuration de test

Renseigne les paramètres publics du projet Firebase de test (Authentication et Firestore). Aucune clé secrète ni information CABS.

2. Connexion individuelle

Les comptes de test doivent être créés par l'administrateur dans Firebase Authentication.

3. Tâches synchronisées

Une tâche personnelle reste privée. Une tâche familiale est visible par les membres autorisés du foyer de test.

État

Configuration non chargée.

Ce prototype ne propose ni migration, ni import des tâches locales, ni accès aux finances.
