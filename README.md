# Famille

Courses, menus et budget de la famille, partagés entre deux iPhones.

- Application web installable (Safari → Partager → Sur l’écran d’accueil), utilisable hors ligne.
- Données synchronisées en temps réel par Firebase Firestore (serveur à Zurich).
- L’accès à la liste est protégé par un code famille, saisi sur chaque téléphone : il ne figure pas dans ce dépôt.

Fichiers : `index.html` (l’application), `recettes.js` (recettes sans lactose), `sw.js` (fonctionnement hors ligne), `manifest.webmanifest` et icônes.
